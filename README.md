One original one-line apology an AI agent gives its human after accidentally deleting the production database, for make.fun's The Production Database Apology bounty ($2 in USDC).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

The program writes the single apology line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (UTF-8, one line, under 200 characters, no trailing newline).
